# MindMetrics AI 🧠

AI-powered mental wellbeing score prediction system built with
Machine Learning, FastAPI, React, TypeScript and PostgreSQL.

## Tech Stack

### Machine Learning

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Recharts

### DevOps

- Docker
- Docker Compose
- Nginx
- GitHub Actions
